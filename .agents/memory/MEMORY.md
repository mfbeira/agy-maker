## 🎯 Como Usar Esta Memória

### Para Agentes de IA
1. Leia este índice (`MEMORY.md`) primeiro
2. Se precisar mais contexto sobre um tópico, abra o arquivo correspondente
3. Use o contexto para entender o projeto em profundidade

### Para Desenvolvedores Humanos
1. Atualize **frequentemente** — quanto mais rich, melhor a IA trabalha
2. Revise na **retrospectiva** — padrões e lições aprendidas evoluem
3. **Referencie em PRs** — "Ver MEMORY.md, ADR-003"
