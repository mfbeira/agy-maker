# Convenções do Projeto

Defina aqui os padrões e convenções adotados pelo projeto (estilo de código, nomenclatura, organização de arquivos, etc.).

## Padrões
- **Nomenclatura:** Variáveis e funções em inglês (`camelCase`), componentes em `PascalCase`, arquivos de estilo e utilitários em `kebab-case`.
- **Commits:** Mensagens de commit seguindo Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`).
- **Branches:** Branches descritivas com prefixo (`feature/`, `fix/`, `docs/`).
