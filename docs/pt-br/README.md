## 🎯 Princípios do Workspace

1. **Clean Code & Simplicidade:** Desenvolvimento enxuto (YAGNI), sem código morto ou complexidade arbitrária.
2. **Progressive Disclosure:** Carregamento de conhecimento e skills sob demanda, mantendo o consumo de contexto otimizado.
3. **Memória Persistente:** Histórico de decisões técnicas e preferências mantido cross-session em `.agents/memory/`.
