# AGY Maker

Um template corporativo e pessoal para configurar workspaces do Antigravity IDE em segundos.

## O que é?
Esse pacote configura a pasta `.agents` e os arquivos centrais no seu projeto atual, trazendo regras de negócio pré-definidas e agentes (como Skills) para que a IA (Antigravity IDE) ajude a desenvolver com consistência desde o dia 1.

Em qualquer projeto novo, basta rodar:

```bash

```
