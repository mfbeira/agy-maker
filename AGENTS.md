# Antigravity Workspace Configuration

Este arquivo serve como ponto de entrada e roteamento para o Antigravity IDE ler as diretrizes deste repositório.

1. Todas as regras globais de programação estão localizadas em `.agents/rules/`.
2. Todos os agentes especializados (Personas) estão localizados como Skills em `.agents/skills/`.

A IA atuando neste repositório deve assumir o papel de Engenheiro de Software Sênior e utilizar as regras acima como guia base para todas as interações.
